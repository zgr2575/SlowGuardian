# Changelog

All notable changes to SlowGuardian are documented here. This project follows [Semantic Versioning](https://semver.org/).

---

## [9.0.0] – 2025

### Added
- Complete v9 UI redesign with glassmorphism and modern dark theme
- Sidebar navigation system with hover-to-expand behavior
- Multi-tab browser system with session management
- First-boot setup wizard (6-step configuration)
- 4-step user onboarding experience
- Plugin system with 100+ modular features
- Advanced developer/admin panel with real-time user monitoring
- Per-user website blocking in admin panel
- Global site pause functionality with password protection
- Screenshot protection system
- Performance mode for lower-end hardware
- Particle system background animation
- Catppuccin theme variants (Mocha, Macchiato, Frappe, Latte)
- Cyberpunk, Ocean, and Sunset themes
- Custom theme creator with live preview
- ChatGPT integration with custom API key support
- KeyAuth premium authentication system
- Google AdSense integration
- Scramjet proxy backend (beta, premium users)
- Motivational daily quote on homepage
- Search autocomplete with popular site suggestions
- Mobile swipe gesture support for sidebar

### Changed
- Proxy system upgraded to Ultraviolet v3 with improved compatibility
- Settings page rebuilt with new component system
- Games and apps catalogs expanded and redesigned
- About:blank cloaking system improved
- Tab cloaking updated with more disguise options

### Fixed
- Onboarding modal positioning issues
- Modal conflicts between setup and onboarding systems
- Proxy redirect handling for edge-case URLs
- Service worker registration on first load
- Mobile layout overflow issues
